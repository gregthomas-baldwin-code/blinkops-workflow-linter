# Steampipe Report Actions

> Steampipe report actions generate reports using Steampipe checks by querying multiple cloud resources.

<Info>
  **NOTE**

  Steampipe Report Actions are only available on private runners.
</Info>

Steampipe report actions generate reports using [Steampipe checks](https://steampipe.io/docs/check/overview) by querying multiple cloud resources.

# Using Workflow Templates as an Existing Blink User

> Premium users can access, import, and use all templates, free and Premium, in the Workflow Library

<Note>
  **INFO**

  * Premium users can access, import, and use all templates, free and Premium, in the Workflow Library. Free users can access and import all free Workflow, but cannot import premium Workflow.

  * If you're trying to access a template in the [Blink Library](https://library.blinkops.com/workflows) webpage, you'll be redirected to the sign-up page before you can use the template you selected.
</Note>

## Using a Workflow from the Templates Feature in the Blink Platform.

1. In the left-hand side navigation menu, click on the "Template" tab. You will be directed to the "Template" page.

2. Choose a Workflow Template you would like to use and click on the Workflow's name. The Workflow details will be displayed.

<Frame>
  <img src="https://mintcdn.com/blinkops-2/0JKaSiVOyIaH-NI8/img/GettingStarted/ChooseTemplate.gif?s=46a90cc94f6452ea1bec23da6fa4d319" width="1956" height="1080" data-path="img/GettingStarted/ChooseTemplate.gif" />
</Frame>

3. Click the "Download" button.

<Frame>
  <img src="https://mintcdn.com/blinkops-2/0JKaSiVOyIaH-NI8/img/GettingStarted/DownloadTemplate.gif?s=62f6081696dea9d79293a4c50ede658b" width="1956" height="1080" data-path="img/GettingStarted/DownloadTemplate.gif" />
</Frame>

4. A *Try this Workflow* pop-up opens. Select a Workspace and a Pack, click on the "Try Workflow" button. The default Pack is **Home pack**.

<Frame>
  <img src="https://mintcdn.com/blinkops-2/0JKaSiVOyIaH-NI8/img/GettingStarted/LocateTemplate.gif?s=567863d6bbbcec8faaf523294e7a042b" width="1956" height="1080" data-path="img/GettingStarted/LocateTemplate.gif" />
</Frame>

5. You will be directed to the [Workflow Editor](/docs/workflows/building-workflows/workflow-editor) page of the selected Workflow. Edit the Workflow template to suit your needs.

<Frame>

</Frame>

# About Templates

> Browse and import pre-built workflow templates to quickly start automating common tasks in Blink.

Find the Templates Library in the main navigation menu. On the Templates page, in the left-hand pane, search for a template by vendor or use case. Use the search bar at the top of the page to search for a template using keywords.

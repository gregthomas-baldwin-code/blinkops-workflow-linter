# Interactive Actions

> Use interactive actions to collect user input via email, Slack, or Microsoft Teams during workflow execution.

<Info>
  The "Interactive Actions" will have a maximum timeout of `14` days. For more information please visit the [Workflows Runtime Limitations](/docs/workflows/system-limits) section of our documentation.
</Info>

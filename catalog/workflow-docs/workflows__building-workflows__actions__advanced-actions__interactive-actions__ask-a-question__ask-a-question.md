# Ask a Question

> Use the ask a question action to collect user input and offer multiple choices during workflow execution.

## Using *Ask a question*

With this feature, you can ask a question and offer multiple choices. The question is sent to someone via Email, Slack, Microsoft Teams or Google Chat. They can interact with the question by answering it, and their response becomes the output for the next step in a Workflow, helping decide what to do next based on their answer.

<Note>**Note**:The recipient of the question of *Ask a question* steps does not need to be a part of a Blink account.</Note>

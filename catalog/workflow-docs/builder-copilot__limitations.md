# Builder Copilot Limitations

> Known limitations and feature constraints of the Blink Builder Copilot AI assistant.

| Feature | Description | Limit Value |
| - | - | - |
| [The Builder Copilot](/docs/builder-copilot/builder-copilot) | Maximum number of requests a tenant can send to the Builder Copilot to generate workflows or [transform output steps](/docs/builder-copilot/transform-data-output) per minute | `43 requests/minute` |
| [The Builder Copilot](/docs/builder-copilot/builder-copilot) | Maximum amount of data a tenant can process in the Builder Copilot per minute, measured by tokens. | `3 MB/minute` |
